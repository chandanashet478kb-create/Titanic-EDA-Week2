# Titanic Dataset – Exploratory Data Analysis and Visualization

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) and visualization on the Titanic passenger dataset using Python. The objective is to understand the characteristics of passengers, identify patterns and relationships among variables, and extract meaningful insights through statistical analysis and graphical representations.

This project is part of Week 2 of the Data Science internship and builds upon the dataset exploration and preprocessing activities performed in Week 1.

## 📊 Dataset

* **Dataset Name:** Titanic Passenger Dataset
* **Source:** Public Titanic dataset hosted on GitHub
* **Total Records:** 891
* **Total Features:** 12
* **Target Variable:** Survived

The dataset contains passenger information such as age, gender, passenger class, ticket fare, family relationships, cabin details, and survival status.

## 🛠️ Tools and Technologies

* Python
* Pandas – Data manipulation and statistical analysis
* NumPy – Numerical operations
* Matplotlib – Data visualization
* Seaborn – Statistical visualization
* Google Colab – Cloud-based Python environment

## 🔍 Tasks Performed

### 1. Dataset Exploration

* Loaded the Titanic dataset using Pandas.
* Examined the first few records and dataset structure.
* Identified column names, data types, and dataset dimensions.
* Generated descriptive statistics for numerical and categorical features.

### 2. Data Quality Analysis

* Identified missing values in the Age, Cabin, and Embarked columns.
* Checked for duplicate records.
* Examined the dataset for potential anomalies and unusual values.

### 3. Survival Analysis

* Analyzed the overall survival distribution.
* Compared survival outcomes across male and female passengers.
* Examined survival rates among first-, second-, and third-class passengers.

### 4. Data Visualization

Created visualizations to understand the dataset and identify meaningful patterns:

* Survival count bar chart
* Survival distribution by gender
* Survival distribution by passenger class
* Passenger age distribution histogram
* Ticket fare box plot
* Age versus fare scatter plot
* Correlation heatmap
* Survival rate by gender bar chart

### 5. Statistical Analysis

* Calculated the total number of survivors and non-survivors.
* Computed survival percentages by gender and passenger class.
* Examined the average and median passenger age.
* Calculated the average ticket fare.
* Used correlation analysis to explore relationships between numerical variables.

### 6. Interpretation of Findings

* Interpreted the patterns observed in the visualizations.
* Compared survival outcomes across different passenger groups.
* Examined missing values and potential outliers.
* Summarized the important findings and limitations of the analysis.

## 📁 Project Files

* `Titanic_EDA_Week2.ipynb` – Python notebook containing the EDA code, statistical analysis, and visualizations.
* `Titanic_EDA_Graphs.zip` – Collection of generated visualization images.

## 📈 Key Findings

* The analysis covered 891 passengers.
* A total of 342 passengers survived, giving an overall survival rate of 38.38%.
* Female passengers had a survival rate of 74.20%, compared with 18.89% for male passengers.
* First-class passengers had a survival rate of 62.96%, followed by second-class passengers at 47.28% and third-class passengers at 24.24%.
* The average passenger age was approximately 29.70 years, while the median age was 28 years.
* Missing values were identified in the Age, Cabin, and Embarked columns.

These findings describe patterns in the dataset and do not establish that any single variable caused a particular survival outcome.

## 🎯 Conclusion

This project demonstrates how Exploratory Data Analysis can be used to understand a dataset, identify important patterns, and communicate findings through statistical summaries and visualizations.

By using Python, Pandas, Matplotlib, and Seaborn, the analysis provides insights into passenger survival, demographic characteristics, ticket fares, and relationships between numerical variables.

The project strengthened practical skills in data exploration, statistical analysis, visualization, interpretation of results, and analytical thinking.
